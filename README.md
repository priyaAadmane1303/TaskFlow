# TaskFlow – Task Management Website

TaskFlow is a simple and user-friendly task management website that helps users organize their daily tasks and track their progress.

## Features
- User login and profile editing
- Add, edit, and delete tasks
- Set task priority and due dates
- Search, filter, and sort tasks
- Dashboard with task statistics
- Monthly calendar view
- Task notifications
- Dark mode
- Data saved using Local Storage

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage
